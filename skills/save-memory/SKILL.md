---
name: save-memory
description: 整理當前對話的關鍵 context 並存入MEMORY.md，防止 context 爆掉後失憶
---

你現在要執行「記憶儲存」任務。請嚴格按照以下步驟執行，不要省略任何步驟。

## 步驟一：掃描整個對話

從頭到尾掃描完整對話，提取以下資訊：

1. 專案/任務狀態 — 目前在做什麼、進行到哪裡
2. 關鍵決策 — 做了什麼決定，以及決定的理由
3. 技術細節 — 重要指令、路徑、設定、架構、程式碼片段
4. 已完成的事 — 確認完成、不需要再重做的項目
5. 待辦/下一步 — 明確還沒做但需要做的事
6. 踩坑記錄 — 出現過的錯誤與對應解法
7. 使用者偏好 — 對方特別強調、在意或重複提到的事

如果使用者有傳入 $ARGUMENTS，請特別聚焦在該方向，確保相關細節更完整。

## 步驟二：寫入記憶檔案

將整理好的內容追加寫入專案根目錄的`MEMORY.md`。
如果檔案不存在，則建立它。
不要覆蓋舊內容，永遠追加在最後面。

格式如下（嚴格遵守，方便日後搜尋）：

```
## [{今天日期YYYY-MM-DD HH:MM}] 對話記憶快照

### 📌 專案/ 任務狀態
> 用2-3 句話描述目前做到哪裡

###🧠 關鍵決策
> - 決策一（原因）
> - 決策二（原因）

###⚙️ 技術細節
> 重要指令、路徑、設定值、架構說明
> 可以用 code block 保留重要片段

### ✅ 已完成
> - 項目一
> - 項目二

### 🔜 待辦 / 下一步
> - 項目一（優先）
> - 項目二

### 🪤踩坑記錄
> 問題：描述
> 解法：描述

### 💡 使用者偏好/ 注意事項
> 對方特別強調的習慣、限制、或風格要求
```
